# Roadmap

## MVP

- Manifest V3 Chrome extension.
- Replace core GitHub terminology with Adeptus Mechanicus terminology.
- Support GitHub SPA navigation and dynamically loaded content.
- Avoid code blocks, inputs and editable areas.
- Keep GitHub functionality untouched.

## Next

- Add richer terminology coverage for pull request, Actions and release pages.
- Replace selected success indicators with subtle purity seal visuals.
- Add optional popup toggle for enabling/disabling the transformation.
- Add options for terminology intensity and visual theme strength.

## Later

- Add screenshots for Chrome Web Store style documentation.
- Add cross-browser packaging notes.
- Add automated browser smoke tests for representative GitHub pages.
